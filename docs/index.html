Quick reference

The 7 types

nilabsence of a value; missing things and failed lookups are nil
booltrue / false; "", [], {} and nil are falsy
numberone number type — integers and decimals (1, 2.5)
stringimmutable UTF-8 text, interpolated: "Hi, {name}!"; escapes \n \t \\ \" \{
listordered sequence: [1, 2, 3]; index from 0 with items[0]
mapstring keys, fast lookup: { "ada": 36 }; dot access person.name
fnfunctions are values — pass them, store them, return them

Syntax basics

letlet x = 1 · let name : string = "Ada" (optional type hint)
constimmutable binding — assigning to it is an error
fnfn add(a, b) { return a + b } · return type: fn f() : number { ... }
closuresinner fns see and update outer let bindings
controlif ... else, while, for x in ..., break, continue
statementsone per line, no semicolons; braces { } carry over lines
operators+ - * / % · == != < <= > >= · and or not
importnamespaces: import lib/math, then math.fib(10)
comments// to end of line
